## Omarchy

The three features are ports of omarchy.org's front end, which is David Heinemeier Hansson's
work. Omarchy is MIT licensed; the text is in
[LICENSES/MIT-omarchy-site.txt](LICENSES/MIT-omarchy-site.txt).

| Here | From omarchy.org |
|---|---|
| the hero pixel field | `HeroPixelField.tsx` — the lattice, the dither, the clear oval, the stamp |
| the headline | `TypewriterTail.tsx` — the rotation rhythm |
| the music card | `MusicControl.tsx` and `src/lib/music.ts` — the state machine, the meter, the card |
| the play/pause glyphs | radio.omarchy.org's icon set |
| the 22 theme palettes | the home page's themes, collected in [themes.md](themes.md) |

## The track

*We Can Fix Everything (The Ultimate Machine)* is [Kevin Koontz's](https://x.com/koozeex1), by
way of Omarchy Radio. It is not included here — OmaMusic plays a file of your own, via
`OMASEEK_MUSIC_PATH`. Good tune.
